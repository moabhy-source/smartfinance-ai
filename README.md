# 💰 SmartFinance AI — Gestão Financeira Inteligente

## 📌 Sobre o projeto

O SmartFinance AI é um projeto de automação financeira desenvolvido para facilitar o registro, a classificação e a análise de movimentações financeiras.

O sistema integra Google Forms, n8n, inteligência artificial, Google Sheets e Looker Studio.

## 🎯 Problema

O controle financeiro manual pode ser demorado e sujeito a erros de classificação, dificultando a compreensão de receitas e despesas.

## 💡 Solução

Foi desenvolvido um fluxo de automação que:

1. Recebe lançamentos financeiros por formulário.
2. Armazena as informações no Google Sheets.
3. Identifica novos registros por meio do n8n.
4. Utiliza IA para classificar e analisar transações.
5. Atualiza a planilha com os resultados.
6. Apresenta indicadores financeiros em um dashboard interativo.

## 🛠️ Tecnologias utilizadas

- n8n — automação de processos
- Google Forms — entrada de dados
- Google Sheets — armazenamento
- Google Gemini — classificação e análise com IA
- Looker Studio — visualização de dados

## 📊 Funcionalidades

- Classificação automática de transações financeiras
- Análise de receitas e despesas
- Cálculo do saldo financeiro
- Indicador de taxa de economia
- Visualização de despesas por categoria
- Filtros interativos por período e categoria

## 📈 Resultados dos testes

Com seis lançamentos fictícios, o dashboard apresentou:

| Indicador | Resultado |
|---|---|
| Receitas | R$ 4.000 |
| Despesas | R$ 1.400 |
| Saldo financeiro | R$ 2.600 |
| Taxa de economia | 65% |

*Os dados apresentados são fictícios e utilizados exclusivamente para demonstração.*

## 🚀 Objetivo

Demonstrar habilidades práticas em automação de processos, integração de ferramentas, inteligência artificial aplicada e visualização de dados.

## 🔒 Segurança

O projeto utiliza dados demonstrativos. Credenciais e chaves de API não devem ser compartilhadas publicamente.
